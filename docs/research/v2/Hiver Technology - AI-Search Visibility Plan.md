## Quarterly test log

Run the same controlled query set in Google Search (record AI Overview presence and cited URLs), ChatGPT search, Perplexity and Gemini. Log query, country/account context, date, response type, cited source domains, Hiver visibility, competitor visibility, result URL/screenshot and next action. Do not call a citation a ranking or use one observation as a trend.

## Citability actions

Prioritize real entity signals, factual services/products, source-rich cost/comparison/diagnostic pages, approved case studies, clear structured text, consistent organization data, genuine third-party profiles and crawlable internal links. Google explicitly states no additional technical requirement is needed for its AI features beyond core Search eligibility and foundations.[1]
