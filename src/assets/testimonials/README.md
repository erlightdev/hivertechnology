# Testimonial photos

Client headshots used by the home-page testimonial marquee.

- Only add a photo with the person's written permission to publish it alongside their quote.
- Square crop, face centred, at least 160 × 160 px. JPG, PNG or WebP — Astro converts and resizes at build.
- Name files after the person, e.g. `jane-doe.jpg`, then import the file in `src/data/testimonials.ts`.
